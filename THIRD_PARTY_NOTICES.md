# Third-party material

## Owner-supplied design

Visual direction adapted from `stitch_whimsical_kids_drawing_studio.zip` (DoodlePop Studio DESIGN.md, home_hub and guided_lesson_view), supplied by the project owner. Turtle, sunflower, and cat decorative illustrations were downloaded from the Google-hosted asset URLs explicitly referenced by that ZIP's home_hub/code.html. Source screenshot/HTML remain in the task's intermediate work folder, not bundled executable application code. These images are reference-provided material; independent redistribution rights have not been established. Confirm ownership/asset terms before a public release, or replace them with commissioned/original assets.

## Fonts and icons

Comfortaa and Quicksand from Google Fonts are self-hosted unchanged, with their SIL Open Font License notices in licenses/. Material Symbols Rounded from Google's Material Design Icons project is self-hosted unchanged under Apache 2.0; see licenses/. The yellow application icon renders the Material Symbols palette glyph. Font filenames keep their original downloaded data even when the extension says woff2; CSS declares the actual TrueType format returned by Google Fonts.

## Code references

Original Django/Canvas implementation and original step-by-step drawing geometry. No code or artwork copied from Splotch or pflajsman/coloring-book. Their observed features informed the project plan only. See IMPLEMENTATION_PLAN.md for reuse considerations.
